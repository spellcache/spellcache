spellcache reads one `.env` at the repository root: the Next.js app, the
worker, drizzle-kit, Playwright, and `docker compose` for `${...}` interpolation
in `docker-compose.example.yml`. Never commit it.

```bash
cp .env.example .env
```

The tables below are read from [`.env.example`](https://github.com/spellcache/spellcache/blob/main/.env.example)
each time the site is built. **required** variables must be set; **optional** ones
have a default and are commented out in the file. Uncomment a line only to
change its default: an empty value is not the same as an unset one.
